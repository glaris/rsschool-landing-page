# Evgeny Kreshchensky — Drawings Portfolio Project

[Live Demo / GitHub Pages](https://glaris.github.io/rsschool-landing-page/)

This is the initial development phase and a working prototype for a real-world project for the contemporary artist Evgeny Kreshchensky. This specific part serves as a testing ground for layout structures, responsive grids, and dark/light theme switching, focusing entirely on showcasing his original fine art drawings. It represents the foundation for a larger, comprehensive upcoming platform.
